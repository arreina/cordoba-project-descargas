# Córdoba Project — descargas

Aplicación de escritorio para presupuestar la confección de cortinas.

## Descargar

Ve a **[Releases](../../releases/latest)** y descarga el archivo de tu sistema:

| Sistema | Archivo |
|---|---|
| Windows | `CordobaProject.exe` |
| Linux (64 bits) | `CordobaProject-linux-x86_64` |

No hace falta instalar nada más.

- **Windows:** haz doble clic en `CordobaProject.exe`. Si Windows SmartScreen avisa de que la aplicación no es
  reconocida, pulsa «Más información» → «Ejecutar de todas formas».
- **Linux:** dale permiso de ejecución y ábrelo:
  ```bash
  chmod +x CordobaProject-linux-x86_64
  ./CordobaProject-linux-x86_64
  ```

Los presupuestos se guardan en la carpeta `.cordoba-project` de tu usuario.
